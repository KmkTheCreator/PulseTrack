🔥 ***PulseTrack*** 🔥

A native Android GPS fitness tracker for tracking your outdoor activities. And ITS COMPLETELY FREE.

🏃 Running · 🚶 Walking · 🚴 Cycling · 🥾 Hiking

✨ Features

- 📍 Real-time GPS tracking
- 🗺️ Live route map
- 📏 Distance, speed & pace
- ⏱️ Duration & moving time
- ⛰️ Elevation tracking
- 🔥 Calorie estimates
- ⏸️ Pause & resume
- 🔔 Background tracking
- 📊 Activity statistics
- 📚 Activity history
- 🌙 Dark & light mode
- 💾 Local storage
- 📴 Offline GPS recording

🛠️ Made With

- Kotlin
- Jetpack Compose
- Material 3
- MVVM
- Room Database
- Coroutines & Flow
- Fused Location Provider
- Foreground Services
- Google Maps

📥 Installation

Download the latest APK from "Releases" (https://github.com/KmkTheCreator/PulseTrack/releases).

Install the APK → Open PulseTrack → Allow location permissions → Start tracking.

🔐 Privacy

GPS and activity data are stored locally on your device by default.
